# Experiment 1: Install VirtualBox/VMware Workstation with Linux or Windows OS

## Aim
To install and configure Oracle VM VirtualBox or VMware Workstation to run different flavors of Linux or Windows operating systems.


## Procedure

### Installation of VirtualBox on a Windows Host Operating System

- Download the VirtualBox installer executable (`.exe`). Run the installer and click the **Next** button on the welcome screen to begin the setup.

![Step Screenshot](images/step_image_1.png)

- Review the custom setup options (installation path and features) and click **Next** to proceed.

![Step Screenshot](images/step_image_2.png)

- Configure your shortcut preferences and click **Next**.

![Step Screenshot](images/step_image_3.png)

- Click **Yes** to proceed through the network interface warning, which will temporarily disconnect your network.

![Step Screenshot](images/step_image_4.png)

- Click the **Install** button to begin copying files and setting up the software.

![Step Screenshot](images/step_image_5.png)

- Once the installation is complete, click **Finish**. A VirtualBox shortcut icon will now be visible on your desktop.

![Step Screenshot](images/step_image_6.png)


## Results

The installation, configuration, and verification of the VirtualBox hypervisor were successfully completed.
