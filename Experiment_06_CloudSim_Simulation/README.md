# Experiment 6: Simulate Cloud Scenario using CloudSim and Custom Scheduling Algorithm

## Aim
To understand the basics of cloud simulation using CloudSim and create a simple simulation skeleton.

## Procedure

### 1. Create the Java project
- Open Eclipse or any Java IDE.
- Create a new Java project and add the CloudSim library.
- Create a new Java class named BasicCloudSimDemo.

### 2. Write the basic simulation code
A sample starter class is provided in [BasicCloudSimDemo.java](BasicCloudSimDemo.java).

```java
public class BasicCloudSimDemo {
    public static void main(String[] args) {
        System.out.println("CloudSim demo started");
        System.out.println("A host and a virtual machine are ready to process a task");
    }
}
```

### 3. Run the program
- Compile and run the Java file.
- Observe the console output.

### 4. Interpret the result
This simple program acts as a starting point for more advanced simulation tasks such as creating hosts, VMs, and cloudlets.

## Results
The CloudSim project was created successfully and executed with the expected starter output.
